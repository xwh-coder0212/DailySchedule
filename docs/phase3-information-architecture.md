## 1. 导航模型

**单一 Activity + Navigation Compose**。底部 4 个顶层 Tab，各自持有独立返回栈。

```
今日 Home  ·  统计 Stats  ·  记录 Record  ·  项目 Projects
```

| 决策 | 选择 | 理由 |
| --- | --- | --- |
| 顶层容器 | 底部导航栏（4 项） | 4 个入口，拇指可达，无抽屉隐藏成本 |
| Tab 返回栈 | 每 Tab 独立栈（`saveState` + `restoreState`） | 从"今日"进项目详情再切 Tab 回来，位置不丢 |
| 记录页 | 顶部 2 个子 Tab（计时 / 记账） | 一个 Tab 塞两种输入会互相干扰；默认停在"计时" |
| 新建/编辑 | 全屏页，不是 Bottom Sheet | 表单有输入项，Sheet 高度不够且易被键盘挤掉 |
| 返回行为 | 系统返回键 + 左上角返回，行为一致 | 不做二次确认退出 |

> 不做 Floating Action Button。FAB 在 4 Tab 结构里会遮挡列表且语义不清，改用页面内的主按钮。

## 5. 浮层、对话框与反馈

| 场景 | 形态 | 说明 |
| --- | --- | --- |
| 有待确认会话 | 首页顶部卡片（非弹窗） | 不打断。用户可忽略 |
| 结束计时 | 无确认，直接结束 | 结束后可编辑，不需要事前确认 |
| 删除会话/消费/项目 | 确认对话框 | 项目删除需提示"历史会话将保留" |
| 记一笔成功 | 轻震动 + Toast | 不弹对话框，不阻断连续记账 |
| 番茄到点 | 系统通知 | 不做应用内弹窗 |
| 导出 | 进度对话框 → 成功提示（含文件路径） | 阻塞式，避免用户误以为没反应 |
| 导入 | 先自动备份 → 选"覆盖 / 合并" → 进度 | 导入是不可逆操作，必须先备份 |

## 6. 本阶段的两个判断（需要你否决或确认）

### 判断一：「消费关联项目」降为 P1

时间轴里的消费被砍掉后，"挂项目"的入口只剩项目详情页的"考研花了 ¥680"。**它的价值尚未被验证。**

**我的判断：MVP 不做的 UI，数据库字段照留。**
- 代价：零（字段已预留，加 UI 是纯前端工作）。
- 收益：记账主流程少一个折叠项，更符合"3 次点击"目标。
- 触发加回的条件：30 天自测中，你主动想看"某个项目花了多少钱"超过 2 次。

### 判断二：统计页 MVP 不画图

饼图、折线图全部 P1。
- 理由：横向条在小屏上信息密度更高、实现更简单、且不容易因为配色和动画引入 bug。
- 图表属于"让数字好看"，不属于"让数字对"。

## 7. 小组件与通知

### 桌面小组件（Jetpack Glance）

| 尺寸 | 内容 |
| --- | --- |
| 中号 4×2 | 当前项目名 + 实时时长 + [开始/结束] 按钮；无计时时显示上次项目 + [开始] |
| 小号 2×1 | 今日学习 / 今日消费 两个数字，点击 → 打开记账页 |

**约束**：Glance 不支持全部 Compose API，小组件 UI 独立实现，不复用 App 内组件。

### 通知

| 通道 | 内容 | 行为 |
| --- | --- | --- |
| `timer_ongoing` | 常驻：项目名 + 时长 + [暂停][结束] | 不可清除（前台服务强制） |
| `pomodoro_alarm` | 番茄到点 | 可清除，点击回 App |
| `review_reminder` | 有待确认会话 | 可清除，点击 → 首页 |

只有 3 个通道。**不做每日提醒、不做超支提醒、不做打卡提醒**——这正是竞品被诟病的通知疲劳。

## 8. 关键流程的页面路径

| 流程 | 路径 |
| --- | --- |
| 开始计时 | 小组件/首页[开始计时] → 记录·计时 → 选项目 → 开始 → **回到首页**（自动切 Tab） |
| 结束计时 | 通知[结束] 或 首页卡片[结束] → 落库 → 首页数字与时间轴刷新 |
| 记一笔 | 小组件/首页[记一笔] → 记录·记账 → 输金额 → 点分类 → **自动保存并返回** |
| 修正忘记结束 | 首页[待确认卡片] → 会话编辑 → 填真实时长 → 保存 |
| 查看项目累计 | 项目 Tab → 点项目 → 项目详情 |
| 导出 | 设置 → 数据导出 → 选目录 → 生成 JSON + CSV |
| 换机 | 旧机导出 → 新机设置 → 数据导入 → 选"覆盖" |

**开始计时后自动切回首页**：计时需要在首页可见，停在记录页没有意义。
