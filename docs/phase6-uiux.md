## 1. 设计原则（先定气质，再谈像素）

| # | 原则 | 落到具体行为 |
| --- | --- | --- |
| 1 | **第一屏给答案，不给入口** | 打开就能看到"今天学了多少、花了多少"，不需要点任何东西 |
| 2 | **数字优先** | 数字是主角，标签是配角。数字字号 ≥ 标签的 2 倍 |
| 3 | **记录路径最短** | 记一笔 3 次点击，开始计时 2 次点击。任何多出来的一步都要有理由 |
| 4 | **颜色只来自项目** | 界面主体保持中性（灰白/深灰），彩色只出现在项目与分类身上。用户自己造的颜色才是这个 App 的颜色 |
| 5 | **不制造情绪** | 消费金额不用红色，学习时间不用渐变。App 只陈述事实，不评价你 |
| 6 | **安静** | 无入场动画堆叠、无彩蛋、无插画吉祥物。滑动和切换用 200ms 淡入淡出 |

### 1.1 由此推出的一条反直觉决策

**"时间账"和"金钱账"不做双色分区。**

常见做法是时间用蓝、钱用橙，视觉上区分两个账本。**这里不做**：

| 理由 | 说明 |
| --- | --- |
| 颜色即评价 | 给消费固定一个颜色，等于给"花钱"附加情绪。超支变红、达标变绿是预算工具的逻辑，而 MVP 没有预算 |
| 噪音 | 主色 + 项目色已经够丰富，再加两个系统色会打架 |
| 区分靠结构 | 分区标题（"时间账"/"金钱账"）＋ 图标 ＋ 位置已经足够 |

两个账本的数字都用 `onSurface` 中性色。**彩色留给项目**，那是用户自己定义的、有语义的颜色。

## 2. 色彩系统

### 2.0 主题模式（三态，2026-09-08 定）

| 模式 | 说明 |
| --- | --- |
| **跟随系统**（默认） | 随系统深色开关自动切换 |
| 浅色 | 强制浅色 |
| 深色 | 强制深色 |

设置页用三段选择器（`DsSegmented`），存 DataStore `theme_mode`。切换即时生效，无需重启。

### 2.2 Dark 主题（必做，不是可选项）

晚上会打开这个 App 回看今天，白底是劝退。

| 角色 | Hex |
| --- | --- |
| `primary` | `#6FD3B4` |
| `onPrimary` | `#04352A` |
| `primaryContainer` | `#12503F` |
| `surface` | `#141615` |
| `surfaceContainerLow` | `#1B1E1C` |
| `surfaceContainerHigh` | `#262A28` |
| `onSurface` | `#E4E6E1` |
| `onSurfaceVariant` | `#A3A69F` |
| `outline` | `#3A3E3B` |

深色模式**不是把浅色反过来**。要点：

- 不用纯黑 `#000000`，用 `#141615`（OLED 上也够省电，且避免文字光晕）
- 不用饱和色做大块背景，深色下高饱和会"发光"
- 阴影在深色下无效，层级靠 `surfaceContainer` 的明度差表达（M3 tonal elevation）

### 2.3 项目色规范化（关键设计）

用户自定义项目颜色时会挑出荧光绿 `#00FF00` 或深蓝 `#000080`，在某一主题下可能完全看不见。**存一套色，运行时按主题派生。**

```kotlin
fun normalizeProjectColor(hex: String, isDark: Boolean): Color {
    val hsl = hex.toHsl()
    return if (isDark) hsl.copy(
        l = hsl.l.coerceIn(0.60f, 0.75f),   // 深色背景下要够亮
        s = hsl.s.coerceIn(0.40f, 0.75f)    // 降饱和，避免"发光"
    ) else hsl.copy(
        l = hsl.l.coerceIn(0.40f, 0.55f),   // 浅色背景下要够深才读得出
        s = hsl.s.coerceIn(0.45f, 0.85f)
    ).toColor()
}
```

保留**色相**（用户要的辨识度），钳制**亮度与饱和度**（系统要的可读性）。

### 2.4 预设色板（12 色，新建项目时选择）

```
#0F6E56 深青    #185FA5 靛蓝    #534AB7 紫      #993C1D 赭石
#3B6D11 橄榄    #854F0B 琥珀    #A32D2D 砖红    #993556 玫红
```

### 2.5 主题包（可替换视觉风格）

2026-09-08 定：整体配色先定为**石墨青**，未来扩展卡通风 / 简洁风 / 少女风等。

架构侧的定义见 Phase 5 §2.2（`ThemePack` 接口 + 禁止硬编码颜色 + 源码扫描单测）。UI 侧的约束：

| 项 | 规则 |
| --- | --- |
| token 命名 | 组件只用语义名（`primary` / `onSurface` / `surfaceContainerLow`），不出现色值 |
| 主题包可覆盖 | 色板、`Shapes`（圆角）、`Typography`（字号字重） |
| 项目色 | 用户自定义色**跨主题包保留**，仍走 §2.3 规范化 |
| 切换入口 | 设置页"外观 → 主题风格"，MVP 只有一项（石墨青），未来加项不影响任何页面 |

**主题风格选择器 MVP 就放进设置页**（即使只有一项）。理由：现在放进去零成本，将来加主题时不用再改导航和状态管理。

### 2.6 动态取色（Monet）

2026-09-08 确认采用，但受限：

| 规则 | 说明 |
| --- | --- |
| 默认关闭 | 默认用主题包配色，保证设计一致性 |
| 仅主题包支持时可用 | 卡通风等强风格主题下**自动禁用并置灰**，"取色"是主题包的可选能力 |
| 作用域 | 只影响 `primary` / `primaryContainer` 等系统色，**不影响用户自定义的项目色** |

原因：Monet 会让主色跟着壁纸变，而项目色需要稳定辨识度。让两者各管一段，互不干扰。

### 2.7 颜色不是唯一的编码维度

项目用 **颜色 + 图标 + 名称** 三重编码。理由：色觉障碍用户（约 8% 男性）不能只靠颜色区分项目，且小尺寸下颜色辨识度会下降。

## 3. 排版

### 3.1 字体

**不打包字体文件。** 中文用系统字体（Noto Sans CJK / 思源黑体），英文数字用系统 Roboto。打包一套中文子集也要数 MB，收益为零。

### 3.2 等宽数字（计时 App 的硬性要求）

```kotlin
val NumberStyle = TextStyle(fontFeatureSettings = "tnum")
```

**所有时长与金额必须用 tabular figures。** 否则秒数从 `1` 跳到 `8` 时数字宽度会变，整个数字串左右抖动——秒表看起来像在抽搐。这是计时类 App 最常见的低级错误。

### 3.3 字号层级

| Token | 字号 | 字重 | 用途 |
| --- | --- | --- | --- |
| `displayNumber` | 34sp | 500 | 首屏三个大数字 |
| `timerNumber` | 40sp | 500 | 计时中的实时时长 |
| `titleLarge` | 20sp | 500 | 页面标题 |
| `titleMedium` | 17sp | 500 | 分区标题、项目名 |
| `bodyLarge` | 15sp | 400 | 正文 |
| `bodyMedium` | 14sp | 400 | 列表副文本 |
| `labelLarge` | 14sp | 500 | 按钮文字 |
| `labelMedium` | 13sp | 400 | 标签、时间戳 |
| `caption` | 12sp | 400 | 对比小字、说明 |

**只有两个字重：400 和 500。** 不用 700——粗体在小屏中文上会糊成一团。

行高：正文 1.5，标题 1.3。

### 3.4 文本缩放

所有字号用 `sp`。**必须支持系统字体放大到 200% 不破版**：

- 数字容器用 `wrapContent` + 允许换行，不写死高度
- 列表项高度用 `minHeight` 而非固定 `height`
- 分区标题 `maxLines = 1` + `Ellipsis`

## 5. 图标

- 来源：`material-icons-extended`（Compose 原生 `ImageVector`，R8 会摇掉未使用的）
- 存储：DB 只存图标**名字符串**（Phase 4 已定），运行时映射到 `ImageVector`
- MVP 精选 **48 个**图标，覆盖：

| 类别 | 示例 |
| --- | --- |
| 学习 | 书本、公式、语言、实验、代码、考试、笔记 |
| 身体 | 跑步、哑铃、骑行、瑜伽、睡眠、医疗 |
| 生活 | 餐饮、交通、购物、家居、衣物、宠物 |
| 工作 | 会议、邮件、编程、设计、写作 |
| 其他 | 娱乐、音乐、游戏、旅行、社交、冥想 |

> 不把 2000+ 个图标全开放给用户。选择过载是真实的成本，48 个精选够用了。**用户新建项目/分类的默认建议从这 48 个里按名称匹配推荐**（输入"数学"高亮书本/公式图标）——这个小功能能省掉每次翻图标的时间。

**验证点**：引入 `material-icons-extended` 后构建一次，确认 R8 摇树后 APK 体积增幅在可接受范围（预期很小，因为都是 `ImageVector` 常量）。

## 8. 状态设计

### 8.1 三个空态（必须写文案，不能只写"暂无数据"）

| 场景 | 图标 | 文案 | 行动 |
| --- | --- | --- | --- |
| 无项目 | 文件夹+ | 先建一个项目，比如"考研数学" | 新建项目 |
| 今日无记录 | 时钟 | 今天还没有记录。开始计时，或补记一笔 | 开始计时 / 记一笔 |
| 无消费 | 钱包 | 今天还没有花钱 | 记一笔 |

**空态是第一次使用的引导位**，也是最容易被敷衍的地方。

### 8.2 加载与错误

| 状态 | 表现 |
| --- | --- |
| 首次加载 | 骨架屏（仅项目列表、时间轴用），其余页面数据快到不需要 |
| 写入中 | 按钮内 16dp 环形进度，禁用按钮防重复点击 |
| 写入失败 | Snackbar + "重试"。**绝不静默失败** |
| 导出/导入 | 阻塞式进度对话框 + 百分比，完成后显示文件路径 |

## 9. 动效与反馈

| 场景 | 动效 | 时长 |
| --- | --- | --- |
| 页面 / Tab 切换 | 交叉淡入淡出（不做横向滑动，底部导航用 slide 会与返回手势冲突） | 150ms |
| 计时卡出现 / 消失 | 高度展开 / 收起 + 淡入 | 200ms |
| 记一笔成功 | 轻震动 10ms + 金额数字淡出 | 100ms |
| 数字变化 | 无动画，靠 tnum 保持稳定 | — |
| 删除确认 | 对话框缩放淡入 | 150ms |

**原则**：动效只用来解释"什么东西从哪来、到哪去"，不用来炫技。全部 ≤ 200ms。

震动只用在两处：记一笔成功、番茄到点。

## 10. 无障碍

| 项 | 要求 |

| 项 | 规范 |
| --- | --- |
| 圆角 | 跟随系统（Android 12+ 自动裁剪），内部元素 12dp |
| 深色 | 跟随系统，`GlanceTheme` 自动切换 |
| 字号 | 2×1 小组件数字 20sp；4×2 时长 28sp |
| 颜色 | 4×2 的项目色同样走 §2.3 规范化 |
| 通知 | 小图标用单色（系统强制）；操作按钮文字用动词："暂停" / "结束"，不用"确定" |

> 小组件 UI 独立实现（Glance 不支持全部 Compose API），但**颜色 token 与字号 token 从 `core/ui` 复用常量**，避免两套视觉走偏。

## 12. 与 Material3 的关系

**用 Material3，但不照搬默认样式。**

| 采纳 | 不采纳 |
| --- | --- |
| tonal elevation 层级 | 默认紫色配色 |
| `NavigationBar` 组件 | FAB（Phase 3 已排除） |
| 组件状态层（hover/pressed） | 默认 80dp 底栏高度（用 64dp） |
| 动态取色（Android 12+，**默认关闭**） | 默认大圆角 shape 全量套用 |

动态取色（Monet）2026-09-08 由"不采纳"改为**采纳但受限**，见 §2.6：默认关闭、强风格主题包下自动禁用、只作用于系统色不覆盖项目色。

**多主题风格（卡通 / 简洁 / 少女等）由 `ThemePack` 抽象承载**，见 §2.5 与 Phase 5 §2.2。MVP 只实现"石墨青"一套，但设置页的选择器入口本期就放进去。

## 13. 阶段总结

### 已确定
- 6 条设计原则，含"双账本不做双色分区"这一反直觉决策
- 完整的 Light / Dark 色彩 token
- **项目色规范化算法**（存一套、按主题派生，保留色相钳制亮度饱和）
- 12 色预设板 + 颜色/图标/名称三重编码
- 字号层级（只有 400/500 两个字重）、**强制 tabular figures**
- 间距 / 圆角 / 控件尺寸 token
- 图标策略（48 个精选 + 名称匹配推荐）
- 21 个基础组件 + 7 个复合组件清单
- 12 个页面的视觉规格
- 3 个空态文案、加载/错误态、动效时长、无障碍清单
- **主题模式三态**（跟随系统 / 浅色 / 深色），默认跟随
- **主题包抽象**（`ThemePack`）：MVP 一套"石墨青"，未来扩展不改组件
